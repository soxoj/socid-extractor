Supported sites
===============

socid_extractor ships **130+ extraction schemes**. Each scheme targets one page shape —
a site's profile HTML, a public JSON API, or an embedded state blob — and maps it onto
the standard :doc:`field ontology <ontology>`.

The full, always-current list
------------------------------

The canonical list is generated from the test suite into
`METHODS.md <https://github.com/soxoj/socid-extractor/blob/master/METHODS.md>`_ — one row
per scheme, with a link to the e2e test that exercises it. It is regenerated by
``revision.py`` (see :doc:`development`), so it never drifts from the code.

A non-exhaustive sample
-----------------------

- **Major networks:** Facebook (user & group pages), Instagram, VK.com, OK.ru, Reddit,
  TikTok, Bluesky, Tumblr, Flickr.
- **Google ecosystem:** Google docs/maps contributions (cookies required), Google Play,
  YouTube.
- **Mail.ru:** my.mail.ru user mainpage, photo, video.
- **Dev / writing platforms:** GitHub, Stack Overflow (HTML + API), LeetCode, Hashnode,
  Medium, Substack, Paragraph, WordPress.org, Virgool.
- **Niche / vertical:** Chess.com, Roblox, MyAnimeList, Scratch, Wikipedia, DailyMotion,
  SlideShare, Weebly, Calendly, Amazon Author, Boosty, Warpcast (Farcaster),
  Fragment (TON/Telegram), Rarible, CSSBattle, lnk.bio, Spatial, TwitchTracker, Max.

Universal detectors
-------------------

A few schemes are not tied to a single domain. Instead of a hard-coded host list, they
match on **engine-specific HTML/JSON markers**, so they work on *any* instance of that
engine:

- **Discourse** forums
- **MediaWiki / Fandom** wikis
- **Mastodon** instances

Because they detect the platform by its markup rather than its URL, self-hosted and
white-label deployments are covered automatically.

Beyond the built-ins
--------------------

- **No scheme for a site?** The opt-in :doc:`AI fallback <ai-fallback>` can extract
  ontology fields from pages that no scheme covers, when their server HTML carries real
  data.
- **Private / proprietary sites?** Load your own schemes via :doc:`plugins`.
- **Want to add a site to the public set?** See :doc:`adding-a-scheme`.
